Bitulya website admin package

Files:
- index.html — сайт з підтримкою даних з адмін панелі.
- admin.html — адмін панель.

Як користуватись:
1. Завантаж index.html і admin.html в одну папку на GitHub Pages / хостинг.
2. Відкрий admin.html.
3. Увійди за логіном і паролем.
4. Редагуй блоки, музику, обкладинки, тексти.
5. Натисни “Зберегти”.
6. Відкрий index.html на тому ж домені.

Важливо:
Це статична адмін панель. Вона зберігає зміни у браузері через localStorage.
Для справжнього завантаження файлів на сервер/GitHub потрібен backend або GitHub API.
